# First pilot: NEVO scene-to-commercial handoff

This is a reviewable acceptance protocol, not a record of stakeholder approval or a real completed production. The current synthetic fixture is disposable; local settlement evidence cannot substitute for a payment provider.

| Criterion | Existing local evidence | Real pilot gate |
|---|---|---|
| Account and current tenant membership | Actual Next sign-in, encrypted TOTP, expiry/recovery/revocation tests | Provision verified participant accounts and approved access |
| Event inquiry and versioned scene | Disk-backed saves, revisions, reload and restart | Real venue scope, dated requirements and agreed measurements |
| Quote from scene quantities | Exact bound scene and price version; persisted quote | Approved SKU/vendor pricing, tax/currency and discount authority |
| Separate client decision | ADMIN cannot impersonate CLIENT; exact quote approval | Actual client review, identity and signature/evidence policy |
| Booking/payment condition | Scope checks and authenticated local evidence | Provider sandbox then actual booking/payment reconciliation; agreed advance/full-payment threshold |
| Frozen finance/production handoff | Original digest survives reload/restart; frozen edits rejected | Finance/production operators confirm output is usable and matches approved scope |
| Recovery | Cold database+uploaded asset restore and integrity checks | Network PostgreSQL/PITR and object storage recovery measured in staging |
| Operational ownership | Secret-free diagnostic metrics and written runbooks | Named operators, alert destinations and approved backup/retention schedule |
| Certification | Chromium desktop/mobile and emulated device checks | Supported browser/physical-device, manual assistive technology, load/soak and approved visual baselines |

Record each real finding with criterion ID, event/version IDs, timestamp, actor, observed result, evidence reference, severity, owner and retest result. Preserve immutable approvals and append corrective evidence. Expansion starts after pilot failures are closed; a marketing landing does not certify that brand's operational workflow.

No production writes, stakeholder decisions or provider configuration are performed by this protocol.
