# Unified ALLB + MAATAA application

Run from the repository root with `npm run setup` and `npm run dev`.
This app serves the ALLB portal, gallery, 36 landings, 36 brand hubs and the preserved MAATAA UI routes.
See [integration details](../../docs/unified-app-integration.md).
