# Approved visual direction

The approved Observatory surface combines the useful structures from the three presented studies: an inspectable sky geometry, a time-scale ruler, measurements with uncertainty, Panchanga fields, an event timeline, and a methods/evidence comparison.

Empirical astronomy and named Vedic/Vedantic traditions remain distinct and traceable. A comparison may be made for a defined, testable quantity; the interface must not imply equivalence, universal agreement, or scientific proof without evidence.

The approved raster reference is `.impeccable/mocks/approved/observatory-dashboard.png`. It is a generated visual comp, not a source of astronomical data or a specification for factual labels. Its values are illustrative. The executable interface is required to label source, method, time scale, frame, and uncertainty.
