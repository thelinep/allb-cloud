## Shared primitives

Landing shell; archive return link; responsive navigation; skip link; editorial split/wide section; serif heading system; hero illustration crop; reference disclosure; local-demo notice; FAQ; closing banner; footer; previous/next navigation. Interaction primitives: keyboard tabs, search/filter directories, local validated forms, illustrative tables, schema browser, selectable workflow, dashboard, timeline, matrix, sessions, lighting sliders, seating diagram, code/copy, review notes, JSON/CSV download, clock input preview, configuration forms.

## Explicit bespoke structures

- ALLB: connected ecosystem orbs and six pursuit cards, then workspace, production, science, code and roadmap.
- MAATAA UI: four token spheres/swatches, component states, paired light/dark samples and code.
- MAATAA Auth: local identity/passkey preview, permissions matrix, reversible session list and audit table.
- MAATAA DB Studio: schema explorer, fixed query fixture, records, lineage and exports.
- Governance: policy form, status-specific review queue, evidence and approval path.
- SHREE: department-specific cost tabs, quantities, review path and reporting examples.
- Observatory: observer-context form and layered hemisphere diagram with zoom.
- Hemant Clock: brass dial with local date/hour input, separate from existing runtime clock.
- Games: the four named reference worlds, category search and selection.
- Product Directory: the twenty named reference concepts, their own artwork crops, filters and selected detail preview.
- NEVO Workflow: stage selector, seating layout, lighting/version previews, illustrative allowance and configuration export.
- TLPS Workflow: reference camera choices, lighting controls, tone/frame selection and configuration export.
- Sankranti: sidereal/tropical comparison sphere plus convention and evidence sections.
- Research / Simulation: distinct ordered inputs, experiment context, assumptions and export views.

Other pages have individually authored compositions built from these shared primitives. They are not 36 independent component trees; the renderer and controls are reused deliberately.

## New decisions and limits

Fonts, exact responsive breakpoints, hover/focus styling, behavior, keyboard arrow navigation, state coupling and exports are new decisions. Local values, statuses, diagrams, readiness and allowances are illustrative. Original claims unsupported by the repository were rewritten or bounded rather than repeated as service capabilities. Source artwork was cropped for illustrations; controls, tables, forms and layouts are actual HTML/CSS/SVG. Low-resolution crops cannot recreate unavailable original product geometry or font assets.
