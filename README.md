# ALLB Cloud

Master repository for ALLB source consolidation.

## Imported source

- `sources/maataa-ui-full-alpha7/`: supplied partial MAATAA UI / Hemant Observatory handoff, including 36 ALLB landing pages and their assets.
- `apps/maataa-ui-route-source/`: standalone Next.js route catalogue and local Auth/scene/spatial demos. It does not yet integrate the actual MAATAA UI package or a production backend.

These are preserved source snapshots, not a unified certified enterprise release. Run each app using its own documented commands. The handoff root package references files not supplied in the archive; it is not a complete MAATAA UI distribution.

No deployment, DNS changes, live authentication, payment, or astronomy telemetry is configured by this import.
